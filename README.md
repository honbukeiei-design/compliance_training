# コンプライアンス研修 10シナリオ版（表示調整済み）

GitHub Pagesでそのまま公開できる静的Web教材です。

## 修正内容

- キャラクター画像の余白・基準位置を統一し、表示位置のズレを抑制
- 画面構成を「左：場面・キャラクター」「右：説明文・選択肢・解説」に再整理
- キャラクター、説明文、選択肢が重ならないようにCSSを全面調整
- 15.6インチPCブラウザを想定した横長レイアウトに最適化
- スマホ横画面では、画面内に収まりやすいコンパクト表示へ自動切替
- 説明文・選択肢・解説を自然な日本語に校正し、必要な説明を追加
- 最終画面に「正答率：○ / 10」を表示
- キャラクター素材を `assets/characters/` に整理し、PNG/SVG一式を同梱

## 構成

- `index.html` : 研修画面
- `assets/main.js` : 10本のシナリオ、選択肢、判定、正答率表示
- `assets/style.css` : 画面デザイン、キャラクター配置、レスポンシブ対応
- `assets/characters/` : キャラクター画像
- `assets/backgrounds/` : 背景SVG
- `assets/ui/` : 情報アイコン
- `app.py` : Streamlit利用時の案内ページ
- `requirements.txt` : Streamlit用依存ファイル

## 利用方法

`index.html` をブラウザで開くと研修を開始できます。GitHub Pagesで公開する場合は、このフォルダの中身をリポジトリ直下にアップロードしてください。

## 編集ポイント

シナリオ本文や選択肢を変更する場合は、`assets/main.js` の `scenarios` 配列を編集してください。キャラクターを差し替える場合は、`assets/characters/` に画像を追加し、各シナリオの `chars` または `after` を変更してください。
